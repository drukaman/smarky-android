# Smarky for Android

Signed Android builds of **Smarky**, the [WorksheetPal](https://www.worksheetpal.com) student companion app.

**Download the latest version:** [www.worksheetpal.com/download](https://www.worksheetpal.com/download)

Direct link to the newest APK: [Smarky.apk](https://github.com/drukaman/smarky-android/releases/latest/download/Smarky.apk)

Requires Android 8.0 or newer. This repository only hosts release files; it contains no source code.
